# PINTAR (Pusat Informasi dan Tracking Layanan Rakyat)

Deskripsi singkat : 
PINTAR (Pusat Informasi & Tracking Layanan Rakyat) adalah platform web yang menyajikan sistem pelacakan transparan dan real-time untuk pengaduan warga, perizinan, hingga bantuan sosial. Website ini menghubungkan masyarakat dan instansi pemerintah dalam satu dashboard untuk memangkas birokrasi dan mempercepat penyelesaian layanan publik.

TECH STACK : 
HTML 
CSS
JavaScript

Cara menjalankan program : dapat langsung di run program di text editor karena kita menggunakan VS CODE yang menggunakan extension live server

Progress saat ini : sudah ada landing page dan form untuk Pengaduan Infrastruktur, Perizinan & Surat, serta Verifikasi Bansos. Serta sudah terssedia chatbot untuk bertanya dan halaman cek status tiket pengajuan. Kemudian sudah terdapat halaman login petugas Admin yang untuk mengecek, menindak lanjuti, dan memverifikasi laporan masyarakat.
